Despre proiect

Un ghid modern pentru restaurantele din oraș

Această versiune folosește AJAX cu funcția fetch(). Datele restaurantelor sunt păstrate în fișierul restaurante.json, iar JavaScript le citește și creează cardurile automat în pagină.

Tehnologie folosită

Ce face AJAX în acest site?

AJAX permite încărcarea datelor fără reîncărcarea paginii. În proiect, JavaScript citește lista de restaurante din restaurante.json și o afișează în secțiunea de mai jos.

Exemplu folosit în proiect:

fetch("restaurante.json")
