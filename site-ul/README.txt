SITE RESTAURANTE ÎN CHIȘINĂU - VERSIUNEA 2

Proiectul conține:
1. index.php - structura HTML + generare restaurante cu PHP
2. style.css - designul site-ului
3. script.js - meniu mobil, filtrare, căutare, buton scroll sus
4. contact.php - procesarea formularului
5. messages.txt - se creează automat după trimiterea unui mesaj

Cum rulezi proiectul:
1. Instalează XAMPP, WAMP sau OpenServer.
2. Copiază folderul site_restaurante_chisinau_v2 în htdocs.
3. Pornește Apache.
4. Deschide în browser:
   http://localhost/site_restaurante_chisinau_v2/index.php

Notă:
Fișierul index.php trebuie rulat prin server local PHP, nu deschis direct ca fișier simplu.
